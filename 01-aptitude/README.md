# Aptitude Preparation Index

## Recommended Study Strategy
To maximize your score in timed campus placement exams like Accenture, follow a systematic 3-phase study order: start with **Quantitative Aptitude** to build core calculation speed, proceed to **Logical Reasoning** for pattern recognition, and finish with **Verbal Ability** for quick comprehension. Allocate a daily time budget of **90 to 120 minutes** (45 mins concept/shortcuts, 45 mins timed practice, 15 mins error review). Log every mock test attempt in the mock-test-logs.md file to track accuracy and speed trends over time.
