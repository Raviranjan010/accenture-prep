# Repository Teaching Standard & Section Structure

To guarantee that every candidate—regardless of prior knowledge—can achieve complete mastery, concept files in this repository follow the core pedagogical structure detailed below.

---

## 📋 The Per-Topic File Skeleton

Every concept guide is organized using these core headers in sequential order:

1. **What this is**: A plain-language explanation of the concept written for an absolute beginner with zero background knowledge. Avoid dense jargon; use clear everyday analogies.
2. **Formula / Rule / Pattern**: Complete mathematical formulas, code syntax, or logical axioms needed. Every formula MUST include a one-line explanation of *WHY* it works.
3. **Shortcut**: Exam-speed shortcuts, mental shortcuts, or time-saving strategies, featuring the trick and why it works.
4. **Worked Examples**: 3-5 worked examples ordered easy $\rightarrow$ medium $\rightarrow$ hard.
5. **Practice Questions (PYQ Bank)**: 15-25 practice questions per topic (20+ for pseudocode, 10+ for coding languages).
6. **Answers**: Separate answer section or paired `-answers.md` file.
7. **Where this appears in the real Accenture test**: One-line test placement indicator.
8. **Recommended videos**: Curated video links with one-line notes.
