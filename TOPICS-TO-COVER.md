# TOPICS-TO-COVER.md — Full 2026 Accenture Syllabus Map

Note: patterns vary by drive/campus/date. Treat this as the maximal union of
what's been reported across recent 2026 drives — better to over-cover than miss
something your specific drive includes.

## Stage 0 — Eligibility / Application
- Eligibility criteria (education %, backlog rules) — 1 reference file only.
- Resume tips specific to Accenture ASE/Advanced ASE roles.

## Stage 1 — Gamified Assessment (replaces old Cognitive MCQ round on most 2026 drives)
- Memory Maze (find key + reach door, spatial recall)
- Path Finder (rotate/connect tiles start→end, 3x3/4x4/5x5 grids)
- Quick-Fire Math / Select Bubbles (order expressions by value under time pressure)
- Any additional decision-making / logic mini-games reported (cover generically:
  "read the objective carefully in first 5 seconds, plan before acting, don't
  panic-click")
- Note: some drives still run the OLD 3-part Cognitive MCQ test instead
  (Numerical, Verbal, Logical Reasoning) — keep the existing MCQ content in the
  repo too, clearly labeled as "classic format, still used on some drives."

## Stage 2 — Technical Assessment
### A. Core CS Fundamentals (MCQ)
- OOP concepts
- DBMS (normalization, joins, keys, SQL basics)
- Operating Systems (process/thread, scheduling, memory management)
- Networking fundamentals (OSI/TCP-IP, DNS, HTTP/HTTPS, ports)

### B. Cloud & Security (NEW — must add)
- Cloud service models: IaaS / PaaS / SaaS
- Deployment models: public / private / hybrid
- Basic security: encryption (symmetric vs asymmetric), authentication vs
  authorization, common attack types (phishing, DDoS) at a conceptual level only
- No exploit/attack-technique detail — conceptual/defensive awareness only

### C. Pseudocode (NEW — must add, dedicated section)
- Loop tracing (for/while, nested loops)
- Recursion trace
- Array/string manipulation trace
- Output-prediction style questions
- Flowchart-to-pseudocode conversion

### D. MS Office / Common Applications (NEW — must add)
- Excel: basic formulas (SUM, IF, VLOOKUP), sorting/filtering, pivot table concept
- Word: formatting, mail merge concept, track changes
- PowerPoint: slide master concept, basic design principles
- General "which application would you use for X" style MCQs

## Stage 3 — Coding Round
- Languages to cover: C, C++, Java, Python, SQL, JavaScript (cover whichever
  the user's drive allows; default to Python + Java + SQL if unspecified)
- Core topics: arrays, strings, searching/sorting, basic recursion, basic DP,
  simple OOP-based problems, SQL query writing (joins, group by, subqueries)
- Difficulty: easy-to-medium, 1-2 problems in the actual test, ~90 min typical

## Stage 4 — Communication Assessment (AI/Versant-graded, ~63 questions, 6 sections)
1. **Reading** — 8 sentences shown on screen, read aloud (pronunciation, pacing, punctuation-based pausing)
2. **Repeat Sentence** — 16 audio sentences, repeat exactly as heard
3. **Sentence Build / Jumbled Sentences** — ~10 scrambled audio sentences, rearrange and speak correctly
4. **Short Answer Questions** — ~24 quick one/two-word spoken answers to simple audio questions
5. **Story Retelling** — hear a short story twice, retell in your own words in ~30 seconds
6. **Open/Spontaneous Speech** — HR-style short spoken answers on simple topics/opinions

Each section: 20–30 second response window, no re-attempts within a section,
sections run back-to-back (pause allowed only between sections, not within).

## Stage 5 — Interview Rounds
- Technical Interview: project deep-dive, DSA basics, resume-based questions
- HR / Managerial Interview: STAR-format behavioral answers, "why Accenture,"
  relocation/shift flexibility questions
- (If applicable) Group Discussion round: current affairs + technology topics
