## Section 1: English Ability Solutions

### Q1: Option C (`were aware of`)
- **Rule**: When subjects are joined by *Neither...nor*, the verb agrees with the subject closest to it. Here, "team manager" is singular, so the verb must be **was aware of** (not "were aware of").

### Q2: Option B (`be`)
- **Rule**: Verbs like *insist, demand, recommend, suggest* trigger the **subjunctive mood**, requiring the base form of the verb (`be completed`).

### Q3: Option B (`Widespread`)
- **Explanation**: *Pervasive* means spreading widely throughout an area or group of people.

### Q4: Option A (`Aggravate`)
- **Explanation**: *Mitigate* means to make less severe or serious; its opposite is *Aggravate* (to make worse).

### Q5: Option C (`of`)
- **Rule**: The adjective *conscious* takes the fixed preposition **of** (*conscious of the facts*).

### Q6: Option A (`1-3-2-4`)
- **Logic**: Sentence 1 introduces cloud computing. Sentence 3 expands on 1 ("This eliminates..."). Sentence 2 introduces a contrast ("However..."). Sentence 4 gives the concluding result ("As a result...").

### Q7: Option B (`Work late into the night`)
- **Explanation**: Idiomatic expression meaning studying or working late into the night.

### Q8: Option B (`Operating as copilot assistants for boilerplate code and tests`)
- **Ref**: Directly stated in the passage: "...modern AI tools act as copilot assistants...".

### Q9: Option B (`Subtle security vulnerabilities`)

### Q10: Option C (`Higher-level system architecture and business logic`)

## Section 5: Pseudocode Tracing Solutions

### Q39: Option C (`25`)
- Initial `a = 5, b = 7`.
- `c = 1`: `b XOR c` = `7 XOR 1` = `6`. `a` becomes `5 + 6 = 11`.
- `c = 2`: `b XOR c` = `7 XOR 2` = `5`. `a` becomes `11 + 5 = 16`.
- `c = 3`: `b XOR c` = `7 XOR 3` = `4`. `a` becomes `16 + 9 = 25`.
- Output = **25**.

### Q40: Option B (`8`)
- Standard Fibonacci sequence generator where `solve(1)=1, solve(0)=1`.
- `solve(2) = 2`, `solve(3) = 3`, `solve(4) = 5`, `solve(5) = 8`.
- Return value = **8**.
