## Solutions & Explanations

### Q1: Option C (`are inspecting`)
- **Rule**: When two subjects are connected by *accompanied by, along with, together with, as well as*, the verb agrees with the **first subject**. Here, "senior architect" is singular, so the correct verb is **is inspecting**.

### Q2: Option C (`via`)
- **Explanation**: "via" indicates passing through or using a specified route/gateway.

### Q3: Option B (`Painstaking`)
- **Explanation**: *Meticulous* means showing great attention to detail; very careful and precise.

### Q4: Option A (`Clarify`)
- **Explanation**: *Obfuscate* means to make obscure, unclear, or unintelligible; its antonym is *Clarify*.

### Q5: Option C (`₹1,250`)
- **Calculation**:  
  $\text{CP} = 800$. Profit $= 25\% \Rightarrow \text{Selling Price (SP)} = 800 \times 1.25 = 1000$.  
  $\text{SP} = \text{MP} \times (1 - 0.20) = 0.80 \times \text{MP} = 1000$.  
  $\text{MP} = \frac{1000}{0.80} = 1250$.

### Q6: Option C (`Either I or II follows`)
- **Explanation**: Complementary pair rule for syllogisms (Some + No with same subject and predicate).

### Q7: Option A (`18`)
- **Tracing**: Even elements are `8` (at index 1) and `10` (at index 3).  
  $\text{Sum} = 8 + 10 = 18$.

### Q8: Option B (`14`)
- `14 AND 7` (Binary: `1110 AND 0111` = `0110` = 6).
- `12 XOR 4` (Binary: `1100 XOR 0100` = `1000` = 8).
- `6 OR 8` (Binary: `0110 OR 1000` = `1110` = 14).

### Q9: Option B (`2NF`)
- **Definition**: 2NF requires 1NF and no partial functional dependencies on composite keys.

### Q10: Option B (`Shortest Job First (SJF / SRTF)`)
- **Explanation**: SJF is mathematically proven to minimize average waiting time for a static batch of processes.
