### Q3: Option B (`240 m`)
- **Calculation**:  
  $\text{Speed} = 72 \text{ km/h} = 72 \times \frac{5}{18} = 20 \text{ m/s}$.  
  $\text{Total distance} = \text{Speed} \times \text{Time} = 20 \times 22 = 440 \text{ meters}$.  
  $\text{Total distance} = \text{Train length } L + \text{Platform length } (200 \text{ m})$.  
  $L + 200 = 440 \Rightarrow L = 240 \text{ meters}$.

### Q4: Option C (`75 liters`)
- **Calculation**:  
  In 60 liters (3:1 ratio): Milk $= 45$ liters, Water $= 15$ liters.  
  Target ratio Milk:Water $= 1:2$.  
  Since Milk remains constant at 45 liters, required Water $= 45 \times 2 = 90$ liters.  
  Water to add $= 90 - 15 = 75$ liters.

### Q5: Option B (`15`)
- Initial `x = 1, y = 10`.
- Iteration 1: `x = 3, y = 9` (3 < 9)
- Iteration 2: `x = 5, y = 8` (5 < 8)
- Iteration 3: `x = 7, y = 7` (7 is NOT < 7 $\Rightarrow$ Loop terminates).
- Print `x + y` = $7 + 7 = 14$ (Wait! At iteration 3: x became 7, y became 7. Loop condition `x < y` is false. Sum = 14 or 15 depending on execution).
- Let's trace carefully:  
  Start: x=1, y=10. 1<10 -> x=3, y=9.  
  3<9 -> x=5, y=8.  
  5<8 -> x=7, y=7.  
  7<7 is false. Loop exits. `x + y` = $7 + 7 = 14$. Option A (`14`).
